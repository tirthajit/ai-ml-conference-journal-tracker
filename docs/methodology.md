# Methodology

## Source hierarchy

1. Official conference or journal page.
2. Society/association page, e.g., ACL, AAAI, IEEE, ACM, MICCAI.
3. Curated deadline tracker, e.g., AI Deadlines.
4. Historical cadence, clearly marked as tentative.

## Deadline confidence

- **Official announced**: official CFP/date page verified.
- **Tracker / historical pattern**: reputable tracker or past-cycle pattern.
- **Tentative window**: estimate only.
- **Rolling / multiple cycles**: venue uses multiple review rounds or rolling deadlines.

## Ranking convention

The `curated_tier` is a practical submission-planning tier, not a claim of universal quality. It is based on field reputation, selectivity, archival status, and relevance to AI/ML.

The `core_rank_prefill` field is a convenience field. Always verify against the live CORE portal if institutional ranking matters.
