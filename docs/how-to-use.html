How to use this tracker

A compact workflow for researchers selecting conferences or journals.

Choosing a conference

  1. Filter by research area and relevance tags.
  2. Shortlist S/A/B venues based on fit and timeline.
  3. Check whether the listed deadline is official or tentative.
  4. Open the source URL and verify the final CFP before planning submission.

Planning backward from a deadline

  • For full conference papers, reserve time for internal review, figures, supplement, and reproducibility checks.
  • For medical-imaging and applied ML work, verify ethics, dataset, and clinical relevance statements early.
  • For NLP venues using ARR-style cycles, verify both the submission cycle and commitment deadlines.

Choosing a journal

  1. Filter by target priority and area.
  2. Verify publisher scope and article type.
  3. Check current journal metrics from the metric source before submission.
  4. Review open-access, APC, and review-time policies from the publisher page.

Contributing corrections

Open a structured update request on GitHub and include a verifiable source URL.
