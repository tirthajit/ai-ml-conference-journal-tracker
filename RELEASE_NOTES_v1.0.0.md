# v1.0.0 — Initial public release

This is the first public release of the AI/ML Conference & Journal Tracker.

## Included

- 117 curated AI/ML and adjacent research conferences.
- 117 current-cycle conference deadline rows.
- 50 reputable journal targets across AI/ML, NLP, computer vision, robotics, data mining, medical imaging, and adjacent areas.
- Searchable GitHub Pages website.
- Canonical CSV data files.
- Excel export for offline use.
- Source registry and methodology page.
- GitHub issue template for update requests.
- GitHub Actions validation workflow.

## Recommended citation

Please cite the repository using the metadata in `CITATION.cff`.

## Caution

Deadlines and journal metrics change frequently. Always verify official CFPs, publisher pages, and ranking sources before making submission decisions.
